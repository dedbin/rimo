# Сборка серверных образов

Из корня подготовленного релиза, где установлен Docker Compose и заполнен
закрытый `.env`, выполнить:

```sh
bash deploy/build-images.sh rimo
```

Имя проекта необязательно: по умолчанию используется `rimo`. Нужный тег
задаётся переменной `RIMO_TAG` в окружении или `.env`; файл читает сам Compose.

Сначала собирается `migrate`: именно этот сервис содержит определение сборки
общего образа приложения, миграций и collaboration. Затем последовательно
собирается `export-worker`. `docker compose build app` здесь недостаточно:
`app` ссылается на готовый образ и не содержит `build`.

Скрипт использует основной `docker-compose.yml`; операторская панель для сборки
не требуется. В конце выводятся имена и фактические immutable IDs только
образов `rimo` и `rimo-export`. Ссылки берутся из `config --images`, без вывода
полной конфигурации с секретами.

Запуск сервисов и применение миграций выполняются отдельной командой
`docker compose up -d --wait` с нужным именем проекта и overlay панели.
