# Технические заметки

- Better Auth 1.7.13 уже содержит emailOTP, таблицы verification и emailVerified.
- requireEmailVerification не ограничивает старые сессии; нужны API и WebSocket gates.
- beforeEmailVerification вызывается после атомарного потребления кода; отказ квоты требует нового кода.
- autoSignInAfterVerification должен быть false, иначе открытая проверка адреса даёт вход без пароля.
- Исходная SQL-миграция проверяется по checksum: добавляется отдельная миграция.
- Контейнер app исходно подключён только к internal-сетям; для SMTP нужна egress-сеть.
- Хук scripts/codex_hook_emulation.py в этом репозитории отсутствует.
- До начала реализации Git: codex/service-rework, только чужая неотслеживаемая plan/vps-selection-2026-10-27/.
- Независимое ревью привело к привязке шага подтверждения к подписанной HttpOnly cookie и сериализации операций OTP отдельным пулом. Финальная статическая проверка этих изменений без замечаний.
- Better Auth при фоновом обновлении отсутствующей сессии выставляет isPending=true. AppGate теперь сохраняет форму регистрации после первой завершённой проверки; отдельный регрессионный тест проверяет сохранение состояния и закрытие защищённого содержимого при выходе.
- SMTP ожидается вне фонового отправщика Better Auth, чтобы ошибка доставки доходила до формы; сетевое ожидание не удерживает блокировку OTP.
- PostgreSQL-тесты запускаются последовательно: Better Auth интроспектирует все схемы, и параллельный DROP SCHEMA другого теста нарушал интроспекцию.
