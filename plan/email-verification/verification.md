# Результат проверки подтверждения почты

Проверено 28 октября 2026 года. Ветка: `codex/email-verification`.

## Готовое поведение
- Регистрация и существующие владельцы подтверждают почту кодом; затем используется вход с паролем.
- Незавершённые регистрации не занимают места, старые владельцы сохраняют места и доски.
- API и WebSocket проверяют статус подтверждения. Анонимные участники продолжают работать по приглашению.
- SMTP с TLS/STARTTLS, понятные ошибки доставки, лимиты отправки и одноразовое использование кодов.
- Шаг подтверждения связан с конкретной регистрацией или входом с проверенным паролем.

## Проверки
- Полный PostgreSQL-прогон: 862 прошли, 17 пропущены (до добавления последнего UI-теста и проверки мониторинга).
- Дополнительные компонентные проверки после исправления фонового обновления: 29/29.
- Проверки мониторинга после исключения незавершённых регистраций из квоты: 12/12.
- Все 6 браузерных сценариев прошли на production-сборке, отдельной временной БД и локальном SMTP с STARTTLS.
- Lint, TypeScript, production build и postbuild совместной работы прошли.
- `npm audit --omit=dev --audit-level=high`: 0 уязвимостей.
- Независимое ревью: замечания исправлены; итоговая статическая проверка блокировок и UI без замечаний.

## Развёртывание
Производственные данные и SMTP не изменялись. Для включения на сервере нужны реквизиты SMTP, проверка доставки, полная резервная копия и совместное обновление приложения и collaboration по README.
