# Отчёт владельцу Rimo

Дата снимка состояния: 27 октября 2026 года.

- `Rimo-progress-2026-10-27.pdf` - итоговый отчёт, 8 страниц A4.
- `report.html` - исходный документ; использует локальные шрифты и снимки.
- `screenshots/` - 14 настоящих снимков локального приложения. В PDF включены 9;
  дополнительные показывают редактора, режим просмотра, совместную доску,
  меню архива и сообщение об отзыве доступа.
- `assets/demo-lesson.pdf` - контрольный двухстраничный PDF, скачанный из Rimo.
- `assets/LICENSE-NotoSans.txt` - лицензия локально включённых шрифтов Noto Sans.
- `qa/` - локальные отрисованные страницы, контактные листы и извлечённый текст;
  они воспроизводятся проверочным скриптом и не добавляются в Git.
- `qa-browser.json`, `qa-layout.json`, `qa-pdf.json` - результаты проверки отчёта.
- `verify_pdf.py` - повторяемая проверка PDF и отрисовка его страниц.

## Проверка

PDF проверен двумя независимыми средствами извлечения текста: `pypdf` и PDFium.
Все восемь отрисованных страниц просмотрены. Подписи имеют размер 9,5 pt;
основной текст - 10,8 pt. Проверены ссылка на юридические вопросы, отсутствие
пригласительных ссылок в PDF и запас до нижних колонтитулов.

Через настоящий UI отдельно проверены сохранение после перезагрузки, гостевой
вход, совместная работа, локальная отмена, живая смена роли, отзыв доступа,
две страницы PDF и восстановление архива с материалами и именами страниц.
Созданные только для этого отчёта четыре доски удалены; четыре DELETE вернули 204.

Нагрузочные тесты проекта здесь заново не запускались. Числа 696 passed и
16 opt-in skipped, сборка и GitHub Actions взяты из зафиксированного протокола.
Последний часовой результат дополнительно сверен по
`temp/performance/load-hour-b17-semi64.json`: failed, steadyDurationSeconds
2329.1091178, receive-limit. Новые изменения защитных ограничений не приняты
как подтверждённые. Источники перечислены в самом отчёте.

Для повторной проверки запустить `verify_pdf.py` штатным workspace Python.
Для печати HTML в браузере использовать A4, масштаб 100%, нулевые поля,
включённую фоновую графику и отключённые колонтитулы браузера.

После независимого просмотра уточнена подпись архива: бинарная служебная история
доски не равна стеку Undo прежней сессии. PDF и визуальная проверка обновлены.
