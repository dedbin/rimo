# Выпуск Rimo v0.4

## Разрешение и объём
Пользователь принял локальную v0.4 и прямо разрешил GitHub, сервер,
проверку после обновления и удаление завершённой ветки. Перед выпуском
нужно исправить округление границ после повторных +/− и убрать подсказку
«Угол блока сохраняет пропорции. Боковая ручка меняет ширину или высоту.»

Графики, оси, несколько выражений/неравенств, редактирование и навигация,
совместная работа, PDF и архив. Версия 0.4.0, схема документа v2.
App, collaboration и PDF worker обновляются согласованно.

## План
- [x] Исправления и локальные регрессии.
- [x] Независимое code/release review и чистый состав git archive.
- [x] PR, CI и точный проверенный коммит.
- [x] Live preflight, свежая проверенная резервная копия и прежние образы.
- [x] Согласованное переключение с защитой существующих данных.
- [x] HTTPS/WSS, графики/неравенства/округление, PDF/архив, reload и cleanup.
- [ ] Git-финализация, удаление завершённой ветки и итоговый отчёт.

## Границы
Посторонние изменения monitoring, inbox, mail, backup, eslint/TypeScript
и независимые каталоги не входят в релиз. Текущее состояние VPS проверяется
перед адаптацией прежних release scripts; существующая почта, квоты,
секреты, файлы и пользовательские доски сохраняются.

## Статус
После двух «+» воспроизведены `5.120000000000001` и `3.5200000000000005`.
Автоматический zoom теперь удаляет только погрешность порядка нескольких ULP,
а отображение исправляет старые сохранённые хвосты. Ручная точность и нетронутые
поля сохраняются; нормализация не может сделать узкий диапазон недопустимым.
Подсказка удалена. TypeScript, ESLint и 165 тестов графиков прошли;
независимое review затронутой логики не нашло замечаний.

Live preflight подтвердил прежний code release d501d8552254, healthy сервисы,
3 исходные доски и 3 изображения. В работающем release найдены 5 host-only
операционных изменений mail/backup/monitoring. Они сохраняются отдельно после
сборки чистых app/PDF images; inbound mail из /srv/rimo/inbox-deploy не меняется.
Перед переключением проверяются хеши overlay и неизменность посторонних контейнеров.
