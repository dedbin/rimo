# Исследование Rimo v0.4

## Исходное состояние
- База: текущий `master`, Rimo v0.3.0.
- React 18, Next.js 15, TypeScript, совместный SVG-редактор на Yjs.
- Есть личные настройки маркера, линии, лазер, следование и жесты доски.
- Чужие локальные изменения зафиксированы в плане и не относятся к v0.4.

## Библиотеки-кандидаты
- Mafs: React/SVG, готовые Cartesian axes, functions, inequalities, pan/zoom.
  https://mafs.dev/guides/display/mafs
- JSXGraph: самостоятельная интерактивная математическая доска SVG/canvas.
  https://jsxgraph.org/docs/
- mathjs: готовый математический parser; для пользовательского ввода нужен
  ограниченный AST и лимиты, исключающие assignments и тяжёлые операции.
  https://mathjs.org/docs/expressions/security.html

## Архитектура
- Выбраны Mafs 0.21.0 (MIT) и mathjs 15.2.0 (Apache-2.0), версии закреплены.
- Общий GraphPlot используется на доске и через SSR в offline PDF worker.
- Graph=7 — новый тип слоя без изменения прежних enum values/schema version.
- Хранятся формулы и диапазоны, готовые точки/HTML/SVG в документ не записываются.
- Каждая строка — вложенная Y.Map; правки полей независимы между участниками.
- Пользовательский ввод разбирает mathjs; scalar AST whitelist ограничен 96 узлами,
  глубиной 16 и длиной 256. JS eval/new Function не используются.
- Максимум 12 отображаемых строк; запас хранения 256 сохраняет параллельные
  добавления у лимита. Лишние строки доступны для скрытия и удаления.
- Сегментация разрывов исправляет соединение полюсов в исходном sampler Mafs.
- Неравенства поддерживаются в явной форме y < f(x) и x >= f(y), также Unicode.
  Произвольные неявные отношения вроде x^2+y^2<4 не входят в v0.4.
- Размер графика ограничивается для вычислений; preview resize масштабирует готовое
  изображение, без повторного вычисления на каждом pointermove.
- В PDF действует общий budget 64 непустых включённых выражения, повторения на
  разных страницах учитываются.
- При боковом resize математический диапазон растёт от противоположного края;
  при пропорциональном resize за угол диапазон не меняется.

## Локальное окружение
- Отдельные БД rimo_v04_app/rimo_v04_test в проверенном локальном PostgreSQL.
- App localhost:3004, collaboration localhost:1238, PDF localhost:3104.
- Приватные runtime settings и журналы — temp/v04-local/, вне Git.
- SMTP использует уже существующий локальный тестовый ящик; внешних писем нет.

## Итоговые уточнения
- Разделение полюсов дополнено подсказками из проверенного mathjs AST:
  знаменатели, отрицательные степени и tan. Производная вычисляется с
  simplify:false, до 32 исходных узлов и 8 попыток; результат проходит тот же
  scalar whitelist. До 16 подсказок/сегментов; конечные острые вершины не разрываются.
- GraphPlot и редактор загружаются по требованию. Первичная загрузка страницы
  доски после разделения пакетов уменьшилась с 780 до 578 kB по Next build.
- На телефоне редактор становится нижней панелью до 45dvh; при открытии блок
  помещается в свободную область, не перекрывая шапку, таймер и панель выделения.
- Минимальный диапазон zoom имеет запас на погрешность floating point, чтобы
  область оставалась допустимой и сохранялась при больших координатах.
- Транзитивный KaTeX Mafs заменён через override на уже используемый 0.18.10:
  production npm audit — 0 уязвимостей. Лицензии сохранены в public/licenses/GRAPH-NOTICES.txt.

## Инструментальные исправления
- npm cache перенаправлен в temp/npm-cache после EPERM вне workspace.
- TS: регулярное выражение без dotAll для ES2017 и nullable mutable ref.
- Тестовый auth helper учитывает CJS/ESM interop; SSR plot импортирует React для tsx.
- Два recovery UI теста выявили лишнюю SVG-обёртку обычных фигур; исправлено.
- Stop-Process вернул ошибку Windows: завершены только сверенные по PID/commandline
  собственные локальные процессы через taskkill перед пересборкой.
- Мобильная проверка учитывает полпикселя после прокрутки дробного 45dvh.
- Контекст одного documentation patch уточнён перед повторным применением.
