полупрозрачный маркер и пунктирные линии в отдельной ветке `codex/v0.3`.

## Ошибки и ограничения
- `scripts/codex_hook_emulation.py` отсутствует: surrogate hooks неприменимы.
- Проверка физического планшета не заменяется эмуляцией браузера.
- Typecheck нашёл неподдерживаемый `exact` в Testing Library role options;
  исправлено отдельным коммитом `499470b`, typecheck прошёл.
- Первые два отказа unit в recovery UI выявили лишнюю панель при write rejection;
  показ toolbar ограничен синхронизированным соединением без ошибки. Повтор:
  929 passed, 152 opt-in skipped.
- Старые native Sharp DLL заблокировали очистку `.next/standalone`; установленный
  Next повторяет EPERM без конечного лимита. Подтверждены PID/манифест старого
  локального v0.2; его процессы остановлены, сборка успешно завершилась.
- Auto-server teardown Playwright в sandbox Windows завис после 6 успешных
  сценариев; четыре собственных сервиса завершены после проверки identity,
  runner вернул exit 0. Регрессия с разрешённым taskkill завершилась штатно.
