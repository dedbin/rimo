# Наблюдения

- `Color` уже поддерживает `a?: number`, валидатор допускает `0`.
- `createLayer` сейчас создаёт прямоугольник и эллипс только с `fill`.
- SVG-компоненты фигур игнорируют сохранённые `stroke` и `strokeWidth`.
- PDF renderer уже использует заливку, контур и alpha через `rgbToCss`.
- Текущее меню выделения показывает палитру 4 × 2, настройку порядка и удаление.
- Код репозитория чистый. До начала работы была неотслеживаемая папка `plan/vps-selection-2026-10-27/`; сохранить её.
- Пустая заливка хранится как `Color.a = 0`, новый контур имеет толщину 2. Схема документа и PDF renderer уже поддерживают эти данные.
- При снятии заливки со старой фигуры без видимого контура создаётся контур прежнего цвета. Все выбранные фигуры меняются одной undo-транзакцией.
- Смешанное выделение: «Контур»/«Заливка» меняют только фигуры; отдельный «Цвет» отвечает за текст, стикеры и рисование.
- Независимое ревью выявило контраст галочки и передачу ref в Radix; исправлено и подтверждено настоящим Chromium.
- Регрессия `e2e/shape-style.spec.ts` прошла: defaults, независимые цвета, повторное открытие, переход между меню, Escape, перемещение, undo/redo, reload.
- Сценарий подготовки изображений и локальные авторизационные данные находятся только в игнорируемой `temp/shape-preview/`.
- После утверждения код `acaf679808ba` опубликован в PR №11, CI прошёл полностью, тот же source собран в Docker на VPS и развёрнут с резервной копией и проверенным откатом.
- В сценарии обновления использованы наследуемый ERR trap (`set -E`), уникальная временная ссылка при каждом переключении current и проверки Docker без command substitution после установки trap.
- Рабочий HTTPS-сервис прошёл браузерный тест фигур. Изолированные тестовые аккаунт и доска удалены, исходные агрегированные fingerprints полностью совпали.
