# Фигуры без заливки и настройка цвета

## Ошибки и ограничения
- В репозитории нет `scripts/codex_hook_emulation.py`; запуск helper не требуется.
- Для поиска в PowerShell нельзя передавать glob-пути как каталоги `rg`; использовать `--glob`.
- Конфигурация Vitest находится в `vitest.config.mts`.
- Создание ветки потребовало штатной эскалации для записи Git refs. Существующие метаданные bisect сохранены.
- Локальный PostgreSQL запущен с эскалацией: в песочнице pg_ctl не может создать restricted token (87).
- Обновлены старые тестовые селекторы: `.drop-shadow-md` больше не является признаком новой фигуры без заливки.
- В React 18 общий Button не передаёт ref в Radix; у новой палитры используется native button с существующим buttonVariants.
- Для палитры исправлены повторное открытие, перехват кликов закрывающимся меню и Escape без сброса выделения.
- Проверка узкого окна учитывает смещение родительского контейнера и прокрутку страницы.
- В сценарии изменения ролей сравнение позиции через bbox.x давало разницу 1 px из-за удалённого контура 4 px вместо 2 px. Проверка теперь сравнивает центр фигуры; реальная отмена перемещения подтверждена повторным E2E.
