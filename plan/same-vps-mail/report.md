# Исходящая почта Rimo на собственном VPS

28 октября 2026 года собственная отправка почты подключена к рабочему Rimo.
Развёрнутый Git revision: `a3f5997650d911ac4ae6fed203609079d5d4668a`.
Приложение и collaboration используют один образ `rimo:server-a3f5997650d9`.

## Почта

Postfix принимает почту Rimo на приватном порту 587 с обязательными STARTTLS
и авторизацией. Отправителю разрешён только адрес no-reply своего домена;
анонимная отправка, неверный пароль, чужой и пустой sender отклоняются.
Публичных SMTP-портов нет. Доставка к MX получателя требует TLS 1.2 или новее.

Caddy выпустил сертификат smtp-поддомена до 26 января 2027 года. Контейнер
проверяет обновление сертификата раз в минуту и применяет согласованную пару
сертификат/ключ. DKIM RSA2048 сохраняется при пересоздании контейнера.
SMTP-реквизиты и закрытый DKIM-ключ находятся в приватном каталоге сервера.

В DNS добавлены A для SMTP, SPF, DKIM и DMARC. Прежние A-записи сохранены.
DNS-записи проверены на authoritative DNS; успешный Gmail Authentication-Results
дополнительно подтверждает их использование получателем.

## Реальная приёмка

Настоящее письмо «Код подтверждения почты в Rimo» получено Gmail
`2026-10-28T12:06:31Z` во «Входящие». У получателя: SPF pass, DKIM pass,
DMARC pass; транспорт от VPS — TLS 1.3. Код прочитан из полученного письма
и использован в рабочем Rimo. Коды и содержимое закрытой сессии не сохранены
в этом отчёте.

Проверено на рабочем сервисе:

- Регистрация создаёт неподтверждённый аккаунт без сессии; клиентское значение
  registrationPending игнорируется.
- Немедленная повторная отправка возвращает 429 с Retry-After.
- Неверный код отклоняется. Два параллельных запроса с правильным кодом дают
  ровно одно успешное подтверждение.
- После подтверждения сессия появляется при входе с паролем. Повторный вход
  с тем же паролем открывает собственную доску.
- Гость присоединяется по приглашению без подтверждения почты; WebSocket
  синхронизируется с рабочим сервером досок.
- Старая сессия владельца доступна для получения своей сессии, но API досок
  возвращает 403 EMAIL_NOT_VERIFIED; подключение WebSocket отклоняется.
- После удаления только контрольных данных совпали хеши исходных пользователей,
  досок, документов, изображений, приглашений и прав: 2 владельца, 8 гостей,
  1 доска. Очередь Postfix пуста.
