# Развёртывание Rimo на сервере

## Цель

Развернуть текущий Rimo на предоставленном пустом сервере с HTTPS для
`rimo-whiteboard.ru`, создать защищённую страницу прогресса с входящими
сообщениями владельца. Установки и настройка сервера разрешены пользователем.

## Этапы

- [x] Проверить SSH, ОС, CPU/RAM/диск, DNS и занятые порты.
- [x] Подготовить сервер, Docker и воспроизводимое окружение без секретов в Git.
- [x] Развернуть страницу прогресса и проверить отправку/чтение сообщения.
- [x] Развернуть текущую сборку Rimo, применить миграции, создать владельца.
- [ ] Проверить публичные HTTPS/WSS, сохранение, гостя, PDF и восстановление.
- [ ] Настроить обновление, локальные копии и проверки; записать внешние остатки.
- [ ] Провести независимое ревью, коммит и передачу адресов владельцу.

## Решения

- Ветка `codex/service-rework`; чужая папка выбора VPS не включается в коммиты.
- Подключение берёт секреты из игнорируемого `.env.server-access`.
- На скриншоте владельца A `@`/`www` направлены на сервер, проверяем живой DNS.
- Панель не получает токены Codex и не исполняет содержимое входящих сообщений.
- Остатки нагрузочной/правовой приёмки из прежнего протокола сохраняются.

## Ошибки

- В локальном Node нет отдельного пакета dotenv; используем штатный parser.
- Первый просмотр apt прерван Windows-кодировкой stdout на Unicode-символе;
  SSH-helper переведён на UTF-8, состояние удалённой установки проверяется отдельно.
- Авторитетные A-записи есть, но публичные резолверы пока получают NXDOMAIN
  из зоны `.ru`; выпуск публичного сертификата зависит от распространения делегации.
- `compose build app` не строит image: build-конфигурация у migrate.
  PDF image собран; приложение собирается через `compose build migrate`.
- Интерактивный `compose run` забрал остаток скрипта из stdin; локальный SSH-helper
  переведён на запуск отдельного приватного `.sh` файла с закрытым stdin.

## Состояние

Backend и панель healthy; проверены реальные ACL и двусторонний обмен.
Проверяем сохранность при смене каталога релиза, затем публичные HTTPS/WSS/PDF.
